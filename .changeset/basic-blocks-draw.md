Add the `text`, `list` and `image` blocks. Text renders Markdown with raw HTML shown as written and reveals annotated lines one per step; lists reveal one item per step or all at once with `reveal=all`; images resolve `image:` references, fit with `contain` or `cover` and warn when `alt` is missing. Each block also builds as a classic script that registers itself.
