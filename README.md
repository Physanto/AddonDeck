# AddonDeck

AddonDeck is an open source kit for making animated presentations, with any language model or without one.
You write, generate or fill in a short `.deck` text, and AddonDeck turns it into a single `index.html` that opens with a double click: no installation, no server and no internet connection.

## Status

**Under construction.** There is no release yet. The repository, its tooling and its rules are in place, and the packages are being built; nothing is ready to use for presentations today.
