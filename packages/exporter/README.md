# @addondeck/exporter

Builds the single-file HTML export of a deck.

Analyzes a deck, gathers only what it uses and embeds it in a single `index.html` (or a zip). Runs in the browser and in Node, so it never touches the DOM or the file system directly.

> Status: skeleton. The package is private until its first release.
