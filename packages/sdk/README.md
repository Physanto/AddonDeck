# @addondeck/sdk

Contracts and helpers for AddonDeck plugins.

Defines the interfaces that blocks, verbs and adapters implement (`BlockPlugin`, `VerbPlugin`, `BlockContext`, `Animator`). It holds no heavy implementations.

> Status: skeleton. The package is private until its first release.
